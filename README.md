三、核心功能解析
双向匹配：通过技能标签、经验、学历、薪资、地理位置等维度计算匹配度，在职位卡片展示匹配分数，提升投递转化。

即时沟通：求职者与企业可在线聊天，支持文字、图片、语音，配合微信订阅消息做离线提醒。

简历管理：支持在线创建简历与上传附件（PDF/Word），后端解析结构化字段，企业查看需授权或付费。

付费能力：职位置顶、简历下载、企业会员等通过微信支付实现，是平台主要盈利点。

地区分站：支持多城市独立运营，适合地方人才网做区域化布局。

分销推广：通过邀请返佣、海报分享实现裂变拉新。

四、技术架构
前端：原生微信小程序或 UniApp，原生性能更好，UniApp 多端适配更强。

后端：PHP + ThinkPHP 6，MVC 架构，ORM 完善，部署简单。

数据库：MySQL 存用户、企业、职位、简历、投递、订单；Redis 做缓存与队列。

存储：OSS/COS 存头像、简历附件、企业 Logo。

部署：宝塔面板 + Nginx + PHP 7.4+ + MySQL 5.7+，虚拟主机也可运行。

五、搭建流程
